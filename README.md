# Brazilian E-commerce Product Analytics

A product analytics case study based on the Brazilian E-Commerce Public Dataset by Olist.
The project explores customer behavior, evaluates key product metrics, analyzes delivery performance, and identifies business opportunities using SQL, PostgreSQL and Python

## Project Overview

This project simulates the work of product analyst. The aim of this project is to transform SQL-queries and Python Analysis into recommendations and insights

## Business Problem 

Company wants to understand better customer behaviour and increase revenue

## Key Insights

- Most customers make only one purchase.
- Electronics and furniture contribute the highest revenue.
- Delivery time varies significantly across states.
- Longer delivery times are associated with higher cancellation rates.
- Repeat customers spend more on average, while one-time customers spend slightly more money per order

## Business Recommendations

- Increase repeat purchases through loyalty programs
- Improve logistics in regions with long delivery times
- Promote high-performing product categories (health beauty)
